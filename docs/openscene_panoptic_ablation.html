openscene_panoptic_ablation

Two named plans exist in this thesis. This document covers openscene_panoptic_ablation: supervised panoptic segmentation using a frozen OpenScene backbone (OpenSeg-distilled MinkUNet) with a MaskPLS-style mask-transformer decoder, extended with a CLIP token head for text-guided classification and camera cross-attention as the novel contribution.

The companion plan, segment_all_filter_text, covers the SAL pseudo-label pipeline — unsupervised training from raw camera+LiDAR data. Both share the same inference logic at the end: produce all masks first, filter with text.

Four-step build sequence

STEP 1 MaskPLS smoke test on nuScenes mini
Clone MaskPLS. Write nuScenes panoptic dataloader. Run one training epoch on 10 mini scenes. Verify loss decreases, masks appear. Eval PQ on mini val. This validates the dataloader, matcher, and eval pipeline before touching anything else. ~2–3 days.
STEP 2 Backbone swap → OpenScene
Remove MaskPLS's MinkUNet backbone. Load OpenScene pretrained weights. Check feature dimension (run inspection script). Add adapter Linear(openseg_dim → 256). Verify forward pass produces same-shaped decoder output. ~1 day.
STEP 3 CLIP token head + text supervision
Add 3-layer MLP on decoder output predicting 768-d CLIP embedding per query. Wire L_token = cosine distance to class text prototype. Pre-compute 16 nuScenes class prototypes. This enables text-guided classification at inference. ~1 day.
STEP 4 Camera cross-attention (novel contribution)
Add camera cross-attention block in each decoder layer. Extract CLIP ViT-L/14 patch features from 6 nuScenes cameras. Active at both training and inference. This improves RQ (classification quality) — the identified SAL bottleneck. ~2–3 days.

The inference philosophy (same for both plans)

segment_all → filter_with_text
The model never uses text to segment. Segmentation is purely geometry-driven. The model finds every plausible segment in the scene regardless of class. Each segment then gets a predicted CLIP token (768-d vector in CLIP space). At inference, you provide text prompts → encode with CLIP text encoder → cosine similarity with predicted tokens → filter or label. You can change the vocabulary without retraining. You can ask for "ambulance" even though the model never saw that label.

MaskPLS smoke test on nuScenes mini

MaskPLS was written for SemanticKITTI. Running it on nuScenes requires writing a new dataloader. Do not skip this step — it validates the Hungarian matcher, loss functions, and evaluation pipeline before touching the backbone. You want to know the system works before swapping any components.

!
Do NOT reuse OpenScene's data/nuscenes_3d/ or data/nuscenes_2d/ for panoptic training. OpenScene aggregates all ~40 keyframes of a scene into one global point cloud (data/nuscenes_3d/{scene}.pth). Panoptic segmentation needs per-keyframe point clouds — instance IDs only make sense within one sweep. Build NuScenesMaskPLS directly from nuscenes-devkit. The pretrained backbone weights still load perfectly — only the data pipeline is separate.
!
Panoptic encoding: Progress.md §10 has a typo. It says instance_id * 1000 + class_id. The official nuScenes panoptic format is: category_id * 1000 + instance_id. Decode with semantic = pan // 1000, instance = pan % 1000. The dataloader code below uses the correct formula. The verify_mini.py call np.unique(pan//1000) also uses the correct decoding.
!
Smoke test scope: 1–2 training epochs on nuScenes mini only (10 scenes, ~400 samples). Goal is not good PQ — it's confirming loss decreases, masks appear, and the eval script runs without error. Full training on nuScenes full happens after the backbone swap.

What MaskPLS looks like originally (SemanticKITTI)

MaskPLS original design
Backbone: MinkUNet34C → 256-d per-voxel features
Queries: N learnable queries (no thing/stuff split)
Decoder: Mask2Former-style cross-attention (6 layers)
Heads: objectness score + binary mask
Loss: BCE + Dice + objectness focal
Matching: Hungarian on mask cost

No CLIP token head. No text. No camera.
What we add on top
Keep: backbone, decoder, Hungarian matcher, mask loss

Change: backbone (swap MinkUNet34C → OpenScene DisNet frozen, 768-d output)

Add: CLIP token head (3-layer MLP → 768-d per query)
Add: camera cross-attention layer in decoder
Add: L_token = cosine loss to text prototypes
Add: nuScenes thing/stuff query separation

Step 1 — nuScenes panoptic dataloader for MaskPLS

This is the core new code for the smoke test. MaskPLS expects a dataset class that returns sparse tensors + GT masks. Write this first.

dataset/nuscenes_maskpls.pypython
import torch, numpy as np
from torch.utils.data import Dataset
import MinkowskiEngine as ME
from nuscenes.nuscenes import NuScenes
from nuscenes.utils.data_classes import LidarPointCloud
from nuscenes.utils.splits import create_splits_scenes
from pyquaternion import Quaternion

# nuScenes thing classes (semantic IDs 1-10) and stuff classes (11-16)
THING_IDS = list(range(1, 11))   # 10 thing classes
STUFF_IDS = list(range(11, 17))  # 6 stuff classes
VOXEL_SIZE = 0.05   # MUST match OpenScene checkpoint training (0.05m not 0.1m)
RANGE = np.array([-51.2, -51.2, -5.0, 51.2, 51.2, 3.0])

class NuScenesMaskPLS(Dataset):
    def __init__(self, dataroot='/data/nuscenes', version='v1.0-mini', split='train'):
        self.nusc = NuScenes(version=version, dataroot=dataroot, verbose=False)
        self.dataroot = dataroot

        # Build sample list for split
        splits = create_splits_scenes()
        key = 'mini_train' if 'mini' in version and split=='train' \
              else 'mini_val' if 'mini' in version \
              else split
        scene_names = set(splits[key])
        self.tokens = [
            s['token'] for s in self.nusc.sample
            if self.nusc.get('scene', s['scene_token'])['name'] in scene_names
        ]
        print(f"[{split}] {len(self.tokens)} samples from {version}")

    def __len__(self): return len(self.tokens)

    def __getitem__(self, idx):
        token  = self.tokens[idx]
        sample = self.nusc.get('sample', token)

        # ── LiDAR ──
        lidar_sd = self.nusc.get('sample_data', sample['data']['LIDAR_TOP'])
        pc = LidarPointCloud.from_file(self.dataroot + lidar_sd['filename'])
        pts = pc.points.T.astype(np.float32)   # [N, 4]: x,y,z,intensity

        # Range filter
        keep = ((pts[:,0] >= RANGE[0]) & (pts[:,0] <= RANGE[3]) &
                (pts[:,1] >= RANGE[1]) & (pts[:,1] <= RANGE[4]) &
                (pts[:,2] >= RANGE[2]) & (pts[:,2] <= RANGE[5]))
        pts = pts[keep]

        # ── Panoptic GT ──
        version = self.nusc.version
        pan_path = f'{self.dataroot}/panoptic/{version}/{token}_panoptic.npz'
        pan = np.load(pan_path)['data'][keep]   # [N]
        sem = (pan // 1000).astype(np.int32)    # 0–16
        inst= (pan % 1000).astype(np.int32)     # unique per instance

        # ── Voxelize ──
        coords_f = pts[:, :3] / VOXEL_SIZE
        coords_i = np.floor(coords_f).astype(np.int32)  # [N, 3]
        _, vox_idx, inv_idx = np.unique(coords_i, axis=0,
                                         return_index=True, return_inverse=True)
        V = len(vox_idx)
        vox_coords = coords_i[vox_idx]           # [V, 3]
        vox_feats  = pts[vox_idx, 3:]            # [V, 1] intensity
        vox_sem    = sem[vox_idx]                  # [V] dominant semantic per voxel

        # ── Build GT instance masks (things + stuff) ──
        gt_masks, gt_classes = [], []
        # Things: one mask per instance
        thing_pts = (sem >= 1) & (sem <= 10)
        for iid in np.unique(inst[thing_pts]):
            if iid == 0: continue
            pt_mask  = inst == iid
            # Project point mask → voxel mask (voxel "on" if ≥1 point is on)
            vox_mask = np.zeros(V, dtype=bool)
            vox_mask[inv_idx[pt_mask]] = True
            gt_masks.append(vox_mask)
            gt_classes.append(int(sem[pt_mask][0]) - 1)  # 0-indexed
        # Stuff: one mask per class (no instances)
        for sid in STUFF_IDS:
            pt_mask  = sem == sid
            vox_mask = np.zeros(V, dtype=bool)
            if pt_mask.any():
                vox_mask[inv_idx[pt_mask]] = True
            gt_masks.append(vox_mask)
            gt_classes.append(sid - 1)  # 0-indexed overall class

        gt_masks   = np.stack(gt_masks).astype(np.float32)   # [N_inst+6, V]
        gt_classes = np.array(gt_classes, dtype=np.int64)

        return {
            'token':      token,
            'coords':     vox_coords,          # [V, 3] int32
            'feats':      vox_feats,           # [V, 1] float32
            'gt_masks':   gt_masks,            # [N_masks, V] float32 binary
            'gt_classes': gt_classes,          # [N_masks] int64
            'n_things':   len(THING_IDS),      # number of thing classes
            'semantic':   vox_sem,             # [V] for eval
        }


def collate_fn(batch):
    """
    Custom collate: sparse tensor coords need batch index prepended.
    GT masks cannot be stacked across samples (different N_instances per sample).
    """
    coords_list, feats_list = [], []
    for b_idx, item in enumerate(batch):
        b_col = np.full((len(item['coords']), 1), b_idx, dtype=np.int32)
        coords_list.append(np.hstack([b_col, item['coords']]))
        feats_list.append(item['feats'])

    coords = torch.from_numpy(np.vstack(coords_list)).int()
    feats  = torch.from_numpy(np.vstack(feats_list)).float()
    sparse = ME.SparseTensor(feats, coordinates=coords)

    # Return per-sample GT dicts (cannot batch-stack due to variable instance count)
    gt_list = [{'masks': torch.from_numpy(x['gt_masks']),
                'classes': torch.from_numpy(x['gt_classes']),
                'n_things': x['n_things'],
                'token': x['token']} for x in batch]
    return sparse, gt_list

"""
Smoke test: run MaskPLS on nuScenes mini.
Goal: loss decreases, masks exist, eval runs. NOT good PQ.
Runtime: ~15-20 minutes for 2 epochs on mini.
"""
import torch, torch.nn as nn
import MinkowskiEngine as ME
from dataset.nuscenes_maskpls import NuScenesMaskPLS, collate_fn

# ── Import MaskPLS components (from cloned repo) ──
import sys; sys.path.insert(0, 'MaskPLS/')
from models.mask_pls import MaskPLS        # main model class
from models.criterion import MaskPLSLoss   # loss function

# MaskPLS config for nuScenes
# Original MaskPLS config is for SemanticKITTI — adapt these values:
cfg = {
    'backbone': {'in_channels': 1, 'out_channels': 256},  # intensity only
    'decoder': {
        'num_queries': 150,      # 100 thing + 6 stuff + 44 extra buffer
        'num_heads': 8,
        'num_layers': 6,
        'd_model': 256,
        'dim_feedforward': 1024,
        'dropout': 0.0,
    },
    'loss': {
        'weight_bce': 1.0,
        'weight_dice': 4.0,
        'weight_obj': 1.0,
        'focal_alpha': 0.25,
        'focal_gamma': 2.0,
        'aux_weight': 0.5,
    }
}

model  = MaskPLS(cfg).to(device)
loss_fn= MaskPLSLoss(cfg['loss'])
opt    = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)

ds     = NuScenesMaskPLS(version='v1.0-mini', split='train')
loader = torch.utils.data.DataLoader(ds, batch_size=1, shuffle=True,

print("Running smoke test: 2 epochs on nuScenes mini...")
for epoch in range(2):
    model.train()
    total_loss = 0
    for i, (sparse, gt_list) in enumerate(loader):
        sparse = sparse.to(device)
        gt     = {k: v.to(device) if isinstance(v, torch.Tensor) else v

        loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        opt.step()
        total_loss += loss.item()

        if i % 50 == 0:
            print(f"  ep{epoch+1} step{i}/{len(loader)}  loss={loss.item():.4f}")

    print(f"Epoch {epoch+1} avg loss: {total_loss/len(loader):.4f}")
    # Expected: ep1 loss ~3-8 (high, unstable), ep2 loss ~1-3 (decreasing)
    # Any decrease = smoke test passing

print("Smoke test complete. Proceed to backbone swap.")

Architecture overview

Three models exist across the ablation study. Architecturally they share the decoder — only the backbone and additional heads change. Understanding all three together makes the ablation story clear.

Model A1 — MaskPLS baseline (geometry-only)

LiDAR scan
↓ voxelize (0.05m)
↓ MinkUNet34C backbone [V × 256] ← original MaskPLS backbone, geometry-only
↓ Transformer decoder (6 layers)
self-attn → LiDAR cross-attn → FFN
↓ Objectness head → score_i ∈ [0,1]
↓ Mask head → M̂_i ∈ R^V (dot product: query · voxel_features)
↓ Filter by objectness > 0.5
→ Panoptic output (NO text, NO camera)

Model A2 — OpenSeg backbone + CLIP head (this plan, Phase A)

LiDAR scan
↓ voxelize (0.05m)
↓ OpenScene DisNet → [V × 768] ← FROZEN, outputs 768-d directly (no separate proj head)
(MinkUNet18A + 1×1 output conv, distilled on OpenSeg features — already in CLIP space)
↓ Adapter Linear(768 → 256) ← trainable, maps to decoder dim
↓ Transformer decoder (6 layers)
self-attn → LiDAR cross-attn → FFN
↓ Objectness head → score_i ∈ [0,1]
↓ Mask head → M̂_i ∈ R^V
↓ CLIP token head → ĝ_i ∈ R^d_clip ← NEW: 3-layer MLP, predicts CLIP space
↓ At inference: cos(ĝ_i, CLIP_text("car")) → zero-shot class assignment

Model A3 — A2 + camera cross-attention (novel contribution)

LiDAR scan + 6 Camera images
↓
LiDAR path: voxelize → OpenScene backbone [V × d_clip] → Adapter [V × 256]

↓
Transformer decoder (6 layers)
self-attn
LiDAR cross-attn (Q=queries, K=V=lidar_feats)
Camera cross-attn (Q=queries, K=V=cam_feats) ← NEW per-layer block
FFN
↓
Objectness + Mask + CLIP token heads (same as A2)
↓
At inference: same text filtering — but CLIP tokens now enriched with visual context

Step 2 — Backbone swap

After the smoke test passes, remove MaskPLS's original MinkUNet34C and replace it with the frozen OpenScene pretrained backbone. This is the core of the openscene_panoptic_ablation plan.

✓
Why this works without retraining the backbone. OpenScene's pretrained backbone already outputs features in CLIP embedding space (distilled from OpenSeg, which was itself trained to match CLIP text). The features are semantically rich by construction — no gradient needed. Freezing it is not a limitation, it's the point: we're testing whether these pretrained CLIP-aligned features improve panoptic segmentation compared to geometry-only features.

The adapter layer — bridging backbone output to decoder input

✓
Key fact from Progress.md §3: The OpenScene checkpoint uses DisNet — a thin wrapper around MinkUNet18A that already includes the output projection head (1×1 sparse conv → [N, 768]). DisNet outputs 768-d directly. You load DisNet (not raw MinkUNet18A). The adapter Linear(768→256) maps that 768-d CLIP-space output to the decoder's 256-d query space.

class OpenSceneFrozenBackbone(nn.Module):
    """
    Wraps OpenScene's DisNet for use as a frozen feature extractor.

    DisNet architecture (from models/disnet.py + models/mink_unet.py):
      Input:  SparseTensor [N_voxels, 1]   (intensity, voxel_size=0.05m)
      MinkUNet18A U-Net stages (96-d final)
      Output head: 1×1 sparse conv → [N_voxels, 768]   ← already CLIP space

    DisNet outputs 768-d directly — no separate proj_head needed.
    We add only a trainable adapter Linear(768→256) for the decoder.

    VOXEL SIZE: must be 0.05m to match the checkpoint's training distribution.
    Using 0.1m will cause subtle domain mismatch in the backbone features.
    """
    def __init__(self, d_clip: int = 768, d_model: int = 256):
        super().__init__()
        # DisNet: MinkUNet18A + 768-d output head — confirmed from Progress.md §3.1
        self.backbone = DisNet(in_channels=1, out_channels=d_clip)
        # Trainable adapter: CLIP 768-d → decoder 256-d
        self.adapter = nn.Sequential(
            nn.Linear(d_clip, d_model),
            nn.LayerNorm(d_model),
        )
        self.d_clip  = d_clip   # 768 — confirmed from nuscenes_openseg.pth.tar
        self.d_model = d_model

    def load_openscene_weights(self, ckpt_path: str):
        """
        Load nuscenes_openseg.pth.tar into DisNet. Freeze backbone.
        Adapter stays trainable for Stage 2.

        Checkpoint path on cluster:
          openscene/models/nuscenes_openseg.pth.tar
        """
        ckpt  = torch.load(ckpt_path, map_location='cpu')
        # OpenScene saves under 'state_dict' key
        state = ckpt.get('state_dict', ckpt.get('model_state_dict', ckpt))
        # Strip DataParallel 'module.' prefix if present
        state = {k.replace('module.', ''): v for k, v in state.items()}

        miss, unex = self.backbone.load_state_dict(state, strict=False)
        print(f"DisNet loaded. Missing: {len(miss)}, Unexpected: {len(unex)}")
        # Expected: missing=0, unexpected=0 (or just adapter keys)
        if miss: print("  Missing keys:", miss[:5])

        # Freeze entire DisNet — only adapter trains in Stage 2
        for p in self.backbone.parameters():
            p.requires_grad_(False)
        self.backbone.eval()
        print(f"DisNet frozen. d_clip={self.d_clip}. Adapter is trainable.")

    def forward(self, sparse: ME.SparseTensor) -> tuple:
        """
        Returns:
          f_clip:  [V, 768] — L2-normalised CLIP-space features (for token loss)
          f_adapt: [V, 256] — adapter output (for decoder LiDAR cross-attn K,V)
        """
        with torch.no_grad():
            # DisNet forward: sparse → MinkUNet18A → 1×1 conv → 768-d
            out    = self.backbone(sparse)          # SparseTensor [V, 768]
            f_clip = F.normalize(out.F, dim=-1)   # [V, 768] — already CLIP space
        f_adapt = self.adapter(f_clip)              # [V, 256] — trainable, has grad
        return f_clip, f_adapt

import torch, torch.nn as nn, torch.nn.functional as F

class CLIPTokenHead(nn.Module):
    """
    Predicts a CLIP-space embedding for each decoder query.
    Supervised during training by cosine distance to class text prototypes.
    At inference, enables zero-shot classification via cosine similarity.
    """
    def __init__(self, d_model=256, d_clip=768):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(d_model, d_model),   nn.ReLU(inplace=True),
            nn.Linear(d_model, d_model),   nn.ReLU(inplace=True),
            nn.Linear(d_model, d_clip),
        )

    def forward(self, queries: torch.Tensor) -> torch.Tensor:
        """
        queries: [B, N_q, d_model]
        returns: [B, N_q, d_clip]  L2-normalized — lives in CLIP space
        """
        return F.normalize(self.mlp(queries), dim=-1)

def token_loss(pred_tokens, prototypes, matched_query_idx, matched_class_idx,
               stuff_query_offset=100, n_stuff=6, n_thing_classes=10):
    """
    L_token = cosine distance between predicted tokens and class text prototypes.
    Applied to matched thing queries AND all stuff queries.
    
    pred_tokens:        [N_q, d_clip] for one sample
    prototypes:         [16, d_clip] pre-computed text embeddings
    matched_query_idx:  row indices from Hungarian (thing queries that were matched)
    matched_class_idx:  col indices from Hungarian (which GT instance, for getting class)
    """
    loss = torch.tensor(0.0, device=pred_tokens.device)

    # Thing queries: matched queries only, supervised by their GT class prototype
    if len(matched_query_idx) > 0:
        pred_thing = pred_tokens[matched_query_idx]             # [M, d_clip]
        tgt_thing  = prototypes[matched_class_idx]              # [M, d_clip]
        loss = loss + (1 - F.cosine_similarity(pred_thing, tgt_thing)).mean()

    # Stuff queries: always supervised (one per class, pre-assigned)
    for k in range(n_stuff):
        q_idx   = stuff_query_offset + k                        # query 100, 101, ..., 105
        cls_idx = n_thing_classes + k                           # prototype 10, 11, ..., 15
        loss = loss + (1 - F.cosine_similarity(
            pred_tokens[q_idx].unsqueeze(0),
            prototypes[cls_idx].unsqueeze(0)
        )).mean()

    return loss / (max(1, len(matched_query_idx)) + n_stuff)

Step 4 — Camera cross-attention

Camera features are used as K,V in a cross-attention block injected into each decoder layer. Two encoder options are supported: EVA-CLIP ViT-L/14 (primary, MIM-pretrained, richer spatial features) and CLIP ViT-L/14 (fallback, simpler). Both run online during training and inference — no caching, no blob storage needed.

✓
Design decision: online inference, no caching. Both EVA-CLIP and CLIP ViT-L/14 run as frozen GPU models each training step. No pre-extraction pipeline, no blob storage, no pre-warming. Training is ~45% slower than with caching but avoids all storage infrastructure. The ablation between EVA-CLIP and CLIP is a free extra row.

ENCODER_CONFIGS = {
    'eva_clip': {
        'model_name':  'EVA02-L-14',
        'pretrained':  'merged2b_s4b_b131k',
        'input_size':  336,   # 24×24 = 576 tokens per camera
        'patch_size':  14,    # 336/14 = 24 patches per side
        'd_clip':      768,
        'n_patches':   576,   # 24 × 24
    },
    'clip_vit_l14': {
        'model_name':  'ViT-L-14',
        'pretrained':  'openai',
        'input_size':  224,   # 16×16 = 256 tokens per camera
        'patch_size':  14,    # 224/14 = 16 patches per side
        'd_clip':      768,
        'n_patches':   256,   # 16 × 16
    },
}

class OnlineCameraEncoder:
    """
    Runs camera encoder online every training step.
    No pre-caching needed — extracts patch tokens from CLIP/EVA-CLIP ViT.
    
    EVA-CLIP (primary):   576 tokens/cam @ 336px, richer spatial features
    CLIP ViT-L/14 (fallback): 256 tokens/cam @ 224px, faster
    
    Both output 768-d patch tokens in CLIP-compatible space.
    Use as K,V in camera cross-attention decoder layers.
    """

    def __init__(self, encoder_type: str = 'eva_clip', device: str = 'cuda'):
        cfg = ENCODER_CONFIGS[encoder_type]
        self.cfg    = cfg
        self.device = device
        self.d_clip = cfg['d_clip']
        self.n_patches_per_cam = cfg['n_patches']
        self.n_total_tokens    = 6 * cfg['n_patches']  # 6 cameras

        # Load model — frozen, fp16, eval mode
        model, _, preprocess = open_clip.create_model_and_transforms(
            cfg['model_name'], pretrained=cfg['pretrained']
        )
        self.model     = model.to(device).half().eval()
        self.preprocess = preprocess
        for p in self.model.parameters():
            p.requires_grad_(False)

        # Resize transform to correct input size for this encoder
        self.resize = transforms.Compose([
            transforms.Resize((cfg['input_size'], cfg['input_size'])),
            transforms.ToTensor(),
            transforms.Normalize(
                mean=[0.48145466, 0.4578275,  0.40821073],
                std= [0.26862954, 0.26130258, 0.27577711]
            ),
        ])
        print(f"OnlineCameraEncoder: {encoder_type} | "
              f"{cfg['input_size']}px | {cfg['n_patches']} tokens/cam | d={cfg['d_clip']}")

    @torch.no_grad()
    def _extract_patch_tokens(self, img_t: torch.Tensor) -> torch.Tensor:
        """
        Extract spatial patch tokens from ViT (drop CLS token).
        Works for both CLIP ViT-L/14 and EVA-CLIP ViT-L/14.
        img_t: [B, 3, H, W] fp16
        Returns: [B, N_patches, d_clip] normalised
        """
        v = self.model.visual

        # --- ViT forward pass ---
        x = v.conv1(img_t)                                # [B, C, P, P] patch embed
        x = x.reshape(x.shape[0], x.shape[1], -1).permute(0, 2, 1)  # [B, N, C]
        cls = v.class_embedding.to(x.dtype).unsqueeze(0).unsqueeze(0)
        x   = torch.cat([cls.expand(x.shape[0], -1, -1), x], dim=1)
        x   = x + v.positional_embedding.to(x.dtype)
        x   = v.ln_pre(x)
        x   = v.transformer(x)                            # [B, N+1, C]

        # Drop CLS token, keep only patch tokens
        patch_tokens = x[:, 1:]                          # [B, N_patches, C]
        patch_tokens = v.ln_post(patch_tokens)
        if v.proj is not None:
            patch_tokens = patch_tokens @ v.proj           # [B, N_patches, d_clip]

        return F.normalize(patch_tokens.float(), dim=-1)  # L2 normalise

    @torch.no_grad()
    def encode_cameras(self, cam_image_paths: list) -> torch.Tensor:
        """
        Encode all 6 nuScenes cameras for one sample.
        cam_image_paths: list of 6 image file paths
        Returns: [1, 6*N_patches, d_clip]
            EVA-CLIP:   [1, 3456, 768]   (6 × 576)
            CLIP ViT-L: [1, 1536, 768]   (6 × 256)
        """
        all_patches = []
        for path in cam_image_paths:
            img   = Image.open(path).convert('RGB')
            img_t = self.resize(img).unsqueeze(0).to(self.device).half()
            patch = self._extract_patch_tokens(img_t)   # [1, N_patches, 768]
            all_patches.append(patch)

        # Concatenate all cameras: [1, 6*N_patches, 768]
        return torch.cat(all_patches, dim=1)

    @torch.no_grad()
    def encode_batch(self, batch_cam_paths: list) -> torch.Tensor:
        """
        Encode cameras for a batch of samples.
        batch_cam_paths: list of B lists, each containing 6 paths
        Returns: [B, 6*N_patches, d_clip]
        
        Note: runs sequentially per sample — GPU is busy with this.
        DataLoader prefetch does NOT help here (GPU-only operation).
        Profile overhead before full training.
        """
        return torch.cat([
            self.encode_cameras(paths) for paths in batch_cam_paths
        ], dim=0)

Camera-enhanced decoder layer (unchanged — works for both encoders)

i
The CamEnhancedDecoderLayer is identical for EVA-CLIP and CLIP ViT-L/14 — both produce 768-d tokens. The cam_proj Linear(768→256) projects either to decoder space. The only difference is the number of K,V tokens: 3456 for EVA-CLIP vs 1536 for CLIP. More tokens = slightly higher attention memory but better cross-attention granularity.
models/cam_decoder_layer.pypython
import torch, torch.nn as nn

class CamEnhancedDecoderLayer(nn.Module):
    """
    MaskPLS decoder layer + camera cross-attention.
    Works with EVA-CLIP or CLIP ViT-L/14 — both produce 768-d tokens.

    EVA-CLIP:   cam_kv shape [B, 3456, 768]  (6 cams × 576 patches)
    CLIP ViT-L: cam_kv shape [B, 1536, 768]  (6 cams × 256 patches)

    cam_proj handles both via Linear(768→256).
    """
    def __init__(self, d_model=256, n_heads=8, d_ffn=1024, d_clip=768, dropout=0.0):
        super().__init__()
        self.self_attn   = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        self.lidar_xattn = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        # d_clip=768 works for both EVA-CLIP and CLIP ViT-L/14
        self.cam_proj    = nn.Linear(d_clip, d_model, bias=False)
        self.cam_xattn   = nn.MultiheadAttention(d_model, n_heads, dropout=dropout, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ffn), nn.GELU(), nn.Dropout(dropout),
            nn.Linear(d_ffn, d_model), nn.Dropout(dropout),
        )
        self.n1 = nn.LayerNorm(d_model); self.n2 = nn.LayerNorm(d_model)
        self.n3 = nn.LayerNorm(d_model); self.n4 = nn.LayerNorm(d_model)

    def forward(self, q, lidar_kv, cam_kv=None):
        """
        q:        [B, 106, 256]
        lidar_kv: [B, V,   256]   adapted backbone features
        cam_kv:   [B, P,   768]   camera patch tokens (P=3456 EVA or 1536 CLIP)
                                  or None (camera dropout)
        """
        q = self.n1(q + self.self_attn(q, q, q)[0])
        q = self.n2(q + self.lidar_xattn(q, lidar_kv, lidar_kv)[0])
        if cam_kv is not None:
            kv = self.cam_proj(cam_kv)      # [B, P, 256] — same op for both encoders
            q  = self.n3(q + self.cam_xattn(q, kv, kv)[0])
        return self.n4(q + self.ffn(q))

Inference — segment all, filter with text

At inference, both the camera encoder and CLIP text encoder run live. No pre-cached anything. The model produces all masks, predicts a CLIP token per mask, then text prompts are used to filter or label them.

Inference modes

Mode 1 — panoptic map
Mode 2 — text retrieval
Mode 3 — LiDAR-only fallback

Label every surviving mask with its closest text class. Returns a full panoptic scene segmentation with nuScenes (or any) vocabulary.

inference/panoptic_mode.pypython
import open_clip, torch, torch.nn.functional as F, numpy as np

NUSCENES_VOCAB = [
    'barrier','bicycle','bus','car','construction vehicle',
    'motorcycle','pedestrian','traffic cone','trailer','truck',
    'driveable surface','flat ground','sidewalk',
    'terrain','manmade structure','vegetation'
]

@torch.no_grad()
def run_panoptic(backbone, decoder, token_head, cam_encoder,
                  sparse_input, cam_paths, vocab=None, obj_thresh=0.5):
    vocab = vocab or NUSCENES_VOCAB

    # ── Text vocabulary encoding ──
    clip_text, _, _ = open_clip.create_model_and_transforms('ViT-L-14', pretrained='openai')
    clip_text = clip_text.cuda().eval()
    text_tokens = open_clip.tokenize(vocab).cuda()
    text_embeds = F.normalize(clip_text.encode_text(text_tokens).float(), dim=-1)  # [C, 768]

    # ── LiDAR encoding ──
    f_clip, f_adapt = backbone(sparse_input)      # [V, 768], [V, 256]

    # ── Camera encoding (online — EVA-CLIP or CLIP ViT-L) ──
    cam_kv = cam_encoder.encode_cameras(cam_paths) # [1, 3456/1536, 768]

    # ── Decoder ──
    layer_outs = decoder(f_adapt.unsqueeze(0), cam_kv, training=False)
    out = layer_outs[-1]
    scores = out['objectness'][0, :, 0].sigmoid()  # [106]
    masks  = out['masks'][0].sigmoid() > 0.5       # [106, V]
    q_feat = out['queries'][0]                      # [106, 256]

    # ── CLIP token prediction ──
    tokens = F.normalize(token_head(q_feat.unsqueeze(0))[0], dim=-1)  # [106, 768]

    # ── Filter by objectness ──
    keep   = scores > obj_thresh
    tokens = tokens[keep]; masks = masks[keep]; scores = scores[keep]

    # ── Classify: argmax cosine similarity ──
    sims    = tokens @ text_embeds.T         # [M, C]
    classes = sims.argmax(dim=-1)           # [M] class index

    # ── Flatten to panoptic ──
    V        = f_adapt.shape[0]
    panoptic = torch.zeros(V, dtype=torch.long, device='cuda')
    for rank, q in enumerate(scores.argsort(descending=True)):
        unassigned = panoptic == 0
        m = masks[q] & unassigned
        if m.sum() == 0: continue
        panoptic[m] = (classes[q].item() + 1) * 1000 + rank + 1

    return panoptic.cpu().numpy()  # [V] — semantic_id*1000 + instance_id

You provide a single text query. Only masks that match above a threshold are returned. This is the "segment_all_filter_text" inference pattern.

inference/text_retrieval.pypython
@torch.no_grad()
def retrieve_masks_by_text(result_tokens, result_masks, query: str,
                             threshold: float = 0.5) -> list:
    """
    result_tokens: [M, 768] predicted CLIP tokens for M surviving masks
    result_masks:  [M, V]   binary voxel masks
    query:         text string, e.g. "car" or "ambulance" (zero-shot!)
    threshold:     cosine similarity cutoff (tune on val: 0.4-0.6)
    
    Returns: list of binary numpy arrays, one per matching mask
    """
    clip_text, _, _ = open_clip.create_model_and_transforms('ViT-L-14', pretrained='openai')
    clip_text = clip_text.cuda().eval()
    q_emb = F.normalize(
        clip_text.encode_text(open_clip.tokenize([query]).cuda()).float(), dim=-1
    )  # [1, 768]
    sims = (result_tokens @ q_emb.T).squeeze(-1)  # [M]
    return [result_masks[i].cpu().numpy()
            for i in range(len(sims)) if sims[i] > threshold]

Risk register — camera-specific

EVA-CLIP pretrained weight download fails
Some open_clip pretrained weights are hosted on Hugging Face which HPC clusters may block. Test: python -c "import open_clip; open_clip.create_model_and_transforms('EVA02-L-14', pretrained='merged2b_s4b_b131k')" on login node before job submission. If blocked: manually download to ~/.cache/huggingface/ from a node with internet access.
Camera cross-attn OOM with batch=2
EVA-CLIP: 3456 K,V tokens × 8 heads × 6 decoder layers ≈ large attention matrices. If VRAM > 96GB: reduce to batch=1 + gradient accumulation steps=4. Or reduce EVA-CLIP input from 336px to 224px (256 tokens/cam → same as CLIP fallback).
Online camera encoding blocks training throughput
EVA-CLIP adds ~480ms/step. Over 30 epochs this is ~68 extra A100 hours vs cached. If timeline is tight after mid-term: temporarily switch to CLIP ViT-L (360ms, 97h total) to get results faster, then run EVA-CLIP as final experiment.
cam_proj layer slow to learn EVA-CLIP→decoder mapping
cam_proj is initialized randomly. For first 5 epochs, camera cross-attention may add noise rather than signal. Use higher LR for cam layers (1e-3 vs 1e-4 for rest). Monitor: camera-on PQ should exceed camera-off PQ (from dropout) by epoch 10. If not by epoch 15: reduce cam dropout to 0.1 so model sees camera more often.
